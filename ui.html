VirusTotal Integration

Free VirusTotal API key — enables one-click reputation checks for IPs, domains, hashes, and URLs. Get yours at virustotal.com

Free AbuseIPDB API key — enables IP reputation and abuse confidence scoring. Get yours at abuseipdb.com

Key Rotation

Generate a new Blowfish key and re-encrypt all vault data — IOCs, investigations, threat actors, and audit log. The old key is permanently discarded. This limits exposure if the current key is ever compromised.

Export

Export vault entries as JSON. This is decrypted data — handle according to TLP classification.

Encryption Details

Storage: Blowfish CBC — 16-round Feistel network, 256-bit key, PKCS7 padding — implemented from scratch
Authentication: SHA-256 with 16-byte random salt per user — passwords never stored
Audit log: Encrypted with same Blowfish key alongside vault data
Libraries: Zero external cryptographic libraries used anywhere
